# Numpy-Practice-Notebook--Day-6# 📊 Day 6 — NumPy Practice

This notebook demonstrates the fundamentals of **NumPy**, a powerful Python library used for numerical computing and data analysis.

## 🎯 Objective

The objective of this practice notebook is to understand how NumPy arrays work and how NumPy can be used to perform efficient numerical and mathematical operations.

## 📚 Topics Covered

* Creating **1D, 2D, and 3D arrays**
* Checking array:

  * Dimensions (`ndim`)
  * Shape (`shape`)
  * Size (`size`)
  * Data type (`dtype`)
* **Indexing and Slicing**
* **Reshaping arrays**
* Creating arrays using:

  * `np.zeros()`
  * `np.ones()`
  * `np.arange()`
  * `np.linspace()`
* Mathematical operations on arrays
* **Vectorized operations**
* **Boolean masking**
* **Broadcasting**
* Aggregate functions:

  * `np.sum()`
  * `np.mean()`
  * `np.min()`
  * `np.max()`
  * `np.median()`
* Practical numerical data analysis example
